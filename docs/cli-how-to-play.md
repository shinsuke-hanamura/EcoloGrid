# Ecologrid CLI の遊び方

ターミナルで Ecologrid を遊ぶための手引きです。サーバ(ゲームエンジン)は Docker で動き、CLI はそのクライアントです。
数値は暫定値で、バランス調整により変わります(正は `docs/spec/spec.md` §8、時間の仕様は `docs/spec/time-spec.md`)。
時間はすべて **tick** で数えます(1 tick = ゲーム内の 1 秒。1 分 = 60 tick、1 時間 = 3,600 tick、1 日 = 86,400 tick)。

## 1. 起動

```bash
cd <このリポジトリのルート>
make up                       # サーバを起動(初回は make build が先に必要)
make cli NAME=alice        # 遊ぶ(名前は 24 文字まで)
```

- 対話プレイには**端末(TTY)が必要**です。自分のターミナルで実行してください(Claude Code の `!` 実行では動きません)。
- 画面は 80 桁 × 30 行以上を推奨します。
- 終了は `q`。サーバから自動的に退出します。
- 別のターミナルで `make cli NAME=alice` を実行すると、同じ世界に入れます(他のプレイヤーは、その名前の 1 文字目で見えます。名前は重複できません)。
- サーバの状態確認: `make cli-check` / 停止: `make down`。

### Docker なしで CLI を動かす(T640 上の venv)

サーバは Docker のまま、CLI だけを Python の venv で動かせます(`.venv/` は作成済み。再作成は `make venv`)。

```bash
make play NAME=alice
# 同じ意味: PYTHONPATH=cli .venv/bin/python -m ecologrid_cli play --name alice
```

- サーバは `http://localhost:8000`(T640 の公開ポート)に接続します。別のサーバへは `--server URL` か環境変数 `ECOLOGRID_SERVER`。
- T640 の Python は 3.8 で pip/venv の `ensurepip` が無いため、`make venv` は `venv --without-pip` + `get-pip.py`(3.8 用)で作ります。
- 別マシン(Mac など)からは、`cli/` を置いて `pip install httpx` し、接続先を環境変数 `ECOLOGRID_SERVER` で指定します(IP アドレスやホスト名は、文書に書かず、環境ごとに設定します)。

```bash
export ECOLOGRID_SERVER=http://<サーバのホスト名または IP>:8000
PYTHONPATH=cli python3 -m ecologrid_cli play --name alice     # --server を付けなくてよい
```

## 2. 画面の見方

```
 EcoloGrid  alice  pos=14,32  Day 1 00:04:33 (earth)  20C   ← 名前・座標・ゲーム内の時刻(`t` キーで Tick 273 に切り替え)・気温
 . . . " . . w . ~ ~ ~ . . # # #                         ← マップ(中央が自分。プレイヤーは名前の 1 文字目で表示。自分は白背景・黒文字)
 ...
 Hydration [########--]  78   Energy [########--]  76   Health [##########] 100
 Stamina   [##########] 100   Wakeful [#######---]  71   State Awake   Range 14   ← スタミナ・覚醒度・状態・知覚の範囲
 In view: Player 1  Rabbit 3  Grass 12   ← 知覚の範囲の中の個体数(世界全体は分からない)
 Here: Rabbit                                            ← 足元(自分と同じセル)にいるもの
 > You ate a Rabbit.                                     ← 直近のログ
```

| 記号 | 意味 | 記号 | 意味 |
|---|---|---|---|
| 名前の 1 文字目 | プレイヤー(**自分は白背景・黒文字**、他のプレイヤーは普通の色) | `~` | 水(通行不可) |
| `f` | キツネ(Fox) | `#` | 岩(通行不可) |
| `r` | ウサギ(Rabbit) | `.` | 陸 |
| `F` `R` | **眠っている**キツネ・ウサギ(大文字) | `,` | 種子 |
| `w` | 小麦(Wheat) | `o` | 卵 |
| `"` | 草(Grass) | 空白 | 知覚の範囲の外(見えない) |

同じセルに複数いる場合は、自分 > プレイヤー > Fox > Rabbit > 卵 > Wheat > Grass > 種子 の順で表示されます。
横は 1 セルを 2 文字幅で描いています。

## 3. 操作

| キー | 操作 |
|---|---|
| `w` `a` `s` `d`(または矢印キー) | 北・西・南・東へ 1 歩 |
| `e` | 足元の獲物を食べる |
| `r` | 隣のセルが水のとき、水を飲む |
| `z` | 休憩する(覚醒したまま、体力とスタミナが早く回復する。移動・飲水・食事の操作で終わる) |
| `.` または space | 待機 |
| `x` | 死亡後にリスポーン(ランダムな地点に新しい体で復活) |
| `h` | サイドパネルの **Help** を出す/消す(開いている間に `c` を押すと Config に切り替わる) |
| `c` | サイドパネルの **Config**(設定)を出す(開いている間に `h` を押すと Help に切り替わる) |
| `t` | ヘッダの時間表記を、時刻表記(`Day 1 00:04:33 (earth)`)と tick 表記(`Tick 273`。世界の開始からのゲーム内の秒数)で切り替える |
| `q` | 終了 |

## 3.1 サイドパネル(Side Panel)

マップの横(端末が狭いときは、マップの上に重ねて全面)に出る、情報と操作の領域です。ページは 2 つで、見出しの行に `[Help]  Config` のように、現在のページが `[ ]` で示されます。

| ページ | 開くキー | 内容 |
|---|---|---|
| **Help** | `h` | 現在の進行の速さ(`Tick: 50 ms (x1)`、最速は `Tick: 0 ms (max speed)`)・文字の説明(凡例)・キーの一覧。**ゲームのキーは、開いたまま効く** |
| **Config** | `c` | `1` = **名前の変更**(他のプレイヤーと重複できない。使用中なら、パネルにメッセージが出て、再入力)、`2` = **進行の速さ(tick の間隔、ms)の変更**(0〜1000。`0` または `max` = 待たずに最速。**全プレイヤーのゲームが速く/遅くなる**。変更は 1 秒に 1 回まで)。入力は、パネルの中で行う。**開いている間は、キーをパネルが受け取る**(`q` や移動のキー、`h`・`c` も、入力中は文字) |

- **閉じる・戻る**: `Esc` は 1 つ戻る(入力中 → 項目の選択 → 閉じる。Help は、閉じる)。`h` で Help、`c` で Config を、もう一度押すと閉じる(Config の入力中を除く)。Config の項目の選択では、`h` で Help へ、`c` で閉じる。
- **スクロール**: 端末が低くて、内容が収まらないときは、最下行に `Up/Down:scroll` と、続きがある向き(`^`・`v`)が出て、**`↑` `↓` でスクロール**します。収まっているときの矢印キーは、移動に使われます。
- **狭い端末**(幅 76 桁未満): パネルは、マップの上に重なって、全面に出ます。閉じるとマップに戻ります(ゲームは、そのまま進みます)。

- 北は画面の上、東は右です。
- 水・岩・世界の外には進めません。
- キーを押しすぎると `Too fast (command queue full)` と出ます(コマンドの待ち行列は 8 件まで)。移動は **5 tick に 1 歩**までです(それより速くは進めません)。
- 起動時のオプション: `--time-format clock|tick`(ヘッダの時間表記の初期値)。

## 4. ルール

世界は**進み続けます**(標準では 1 tick = 50 ms)。操作が遅れても、動物は動き、植物は育ちます。ポーズはありません。

### 生命パラメータ

| 項目 | 内容 |
|---|---|
| Hydration(水分) | **気温で決まる速さで**減る(行動では減らない)。標準の気温 20 ℃では、満タン(100)から 0 になるまで約 62.8 時間(225,929 tick)。0 ℃以下では約 80 時間、40 ℃では 5 時間、100 ℃以上では一瞬で 0 になる(`docs/spec/animal-states-spec.md` §6.9)。0 になると脱水症状で Health が減る。 |
| Energy | 時間と移動で減る。満タンから 0 になるまで 2 日 12 時間(216,000 tick)。移動は 1 歩ごとにも少し消費する。0 になると**移動できなくなり**、Health も減る。 |
| Health(体力) | 水分と Energy が足りていれば、**静止しているとき**少しずつ回復する(0 → 100 に 1 日 12 時間)。動いている間(直近 60 tick 以内に行動した間)は回復しない。休憩・睡眠中は速く回復する(8 時間)。0 になると死亡。 |
| Stamina(スタミナ) | **行動で減る**(1 歩 0.005、食べる 0.025、飲む 0.01)。最大値は現在の Health。静止すると Health の 10 倍の速さで、休憩・睡眠中はさらに速く回復する。足りないと `Rejected: exhausted`。快適な気温(10〜30 ℃)を外れると、毎 tick 減る。 |
| Wakeful(覚醒度) | 起きている間、一定の速さで減る(満タンから約 24.5 時間で 0)。眠ると回復する。**低いほど、眠くなる**(入眠は確率で決まり、覚醒度が 0 になる前に眠る)。眠っている間は操作できない(`Rejected: asleep`)。 |

初期値は水分・Energy・Health・スタミナともに 100(満タン)です。水分が 0 になると、約 9 時間(32,400 tick)で死亡します(水分と Energy の両方が 0 なら約 4 時間 30 分)。**水分は 2 日以上かけてゆっくり減る**ので、短いプレイでは、渇きはほとんど感じられません。

### 知覚の範囲

- **見えるのは、自分のセル + 距離 r のセルだけ**です(正方形)。範囲の外は、空白で表示されます。
- r は、**知覚の範囲(あなたは 20)× 覚醒度の割合**です。眠くなるほど(覚醒度が下がるほど)狭くなり、眠っている間と、覚醒度が極端に低いときは、**自分のセルだけ**になります(状態バーの `Range` に表示)。
- 範囲の外の動物・植物・地形は、サーバから届きません(世界全体は見えません)。

### 睡眠と休憩

- 覚醒度が下がると、確率的に**眠くなって眠ります**(意思に関係なく)。**1 日に 8 時間ほど眠ります**。いつも眠る時刻(直近 5 回の入眠時刻)が近いほど眠くなりやすく、時刻は少しずつ習慣になります。眠っている間は移動・飲水・食事ができず、操作は `Rejected: asleep` になります。起床は確率的で、覚醒度が十分に回復すると起きます。
- 覚醒度が 0 になると**意識を失い**(`Rejected: unconscious`)、一定まで回復してから通常の睡眠になります。めったに起きません。
- 眠っている間も、水分と Energy は減ります。安全な場所(水の近くなど)で眠りましょう。
- `z` で休憩すると、覚醒したまま、体力とスタミナが早く回復します。
- Fox や Rabbit も眠ります(`F` `R` と大文字で表示)。眠っている間は動かず、食べません。

### 水を飲む

水(`~`)の**隣のセル**に立って `r` を押すと、水分が 10 回復します(押すたびに回復。満タン 100 の 10%、ゲーム内の約 7 時間分)。

### 食べる

- 食べられるのは **Fox・Rabbit・Wheat** です(Grass は食べられません)。
- 獲物と**同じセル**に入り(`Here:` に表示される)、`e` を押します。
- 食べた獲物のエネルギーの 60% が、自分の Energy に加わります。獲物は消えます。
- 獲物が足元にいないと `Rejected: no_prey`、水が隣にないと `Rejected: no_water`、スタミナが足りないと `Rejected: exhausted`、眠っていると `Rejected: asleep` と表示されます。

### 生態系

- Rabbit は Wheat と Grass、Fox は Rabbit・Wheat・Grass を食べます。**動物がプレイヤーを襲うことはありません。**
- 植物(Grass・Wheat)は時間とともに種子(`,`)を飛ばし、種子は発芽して新しい植物になります。**種子は動物が踏むと消えます。**
- 水(`~`)から遠い植物は水分が少しずつ減り、長い時間のうちに枯れることがあります。
- Rabbit と Fox は条件を満たすと繁殖して増えます。
- **動物は、空腹(Energy が 60 未満)のときだけ、触れた獲物を食べます**(眠っている・意識がない・スタミナが足りないときは食べません)。

### 死んだら

画面に `*** YOU DIED ***` と出ます。`x` でリスポーンできます(新しい体で、ランダムな場所から)。

## 5. 遊びのコツ

1. まず `Hydration` が減ってきたら、水辺(`~` のある所)へ向かって `r` で飲みます。
2. `Energy` が減ったら、近くの `w`(Wheat)や `r`(Rabbit)を探します。
3. Wheat は動かないので、確実に食べられる食料です。まず Wheat から食べると安心です。
4. 動物は、水を飲んだり獲物を探したり、ランダムに歩き回ったりします(逃げる動きはしません)。移動の間隔は Rabbit 20 / Fox 12 / あなた 5 tick/ボクセル(数が小さいほど速い)なので、追えば追いつけます。
5. `World:` の行で、世界全体の個体数の増減を眺めるのも面白いです。生態の周期は長く(Rabbit の妊娠期間は 5 時間 24 分など)、増減はゲーム内で数日かけて現れます。

## 6. 困ったとき

| 症状 | 対処 |
|---|---|
| `play requires a terminal` | 自分のターミナルから実行する(Claude Code の `!` では不可)。 |
| `error: ConnectError ...` | サーバが止まっている。`make up`。 |
| `Reconnecting (server restarted ...)` | サーバが再起動された。自動で再参加するが、世界は初期状態に戻る。 |
| 画面が乱れる | ターミナルを大きくする(80×30 以上)。 |
| プレイヤー名が重複した | 重複は可能。見分けたければ名前を変える。 |
| ターミナルを閉じたらキャラが残った | 正常に終了(`q`)しないと、サーバが 300 秒後に退出させる。それまでキャラは世界に残る。 |

## 7. おまけ: 自動プレイ(ボット)

```bash
make bot NAME=bot1 SECONDS_=60     # 60 秒、水を飲み・食べ・歩き回る
```

ボットを走らせながら遊ぶと、他のプレイヤーが、名前(`bot` なら `b`)の 1 文字目として見えます。サーバの負荷試験にも使えます。
並列に複数起動する場合は `docs/tasks/1_04_cli_client.md` を参照してください。
