# 14 動物の状態(睡眠・覚醒・食事可能)、個体の能力値、体力・スタミナの増減

**状態: 実装済み(2026-11-06。簡略計算モード `lite`・戦闘・落下を除く)。結果は末尾「実装結果」** 仕様: `docs/spec/animal-states-spec.md`(作者指示 2026-11-04・11-05。**睡眠のコアタイムは廃止**。名前 `wakefulness` / `wake_probability` は承認済み)

## 目的
NPC の自動捕食を「空腹で、かつ食事が可能なとき」に限る。「食事が可能」= 意識がある ∧ 体が動く ∧ 安全(戦闘状態でない ∧ 落下中でない)。そのために、動物(Player を含む)に睡眠・覚醒度を導入し、個体の能力値(筋力・精神力・体力)、スタミナ、休憩を加える。睡眠は**覚醒度と入眠・起床の確率だけ**で決める(コアタイムなし)。覚醒度は体力に影響されない。体力・スタミナの消費・回復は、**状態とアクションごとの増減表**で決める。

## 実装順(段階)
- **14a(先行・小さい。推奨は最初に実施)**: 自動捕食を「空腹(Energy < `hunger_threshold`)かつ `can_eat`」に限る。`Animal.can_eat()`(= 意識がある ∧ 体が動く ∧ `is_safe()`)と `is_safe()`(= 戦闘状態でない ∧ 落下中でない)を導入。当面は `can_eat` = `Energy > 0`、`is_safe` = 常に真(戦闘・落下は未実装)。tick 数の値に移行後の草・小麦の枯渇(`docs/tasks/1_13`)への対応。シミュレーションで、検証結果(3 日間維持)を再現することを確認。
- **14b 個体の能力値**: 個体の状態として `max_health`(体力)、`strength`(筋力)、`mind`(精神力)を持たせる。精神力は個体ごとの初期値を持ち、現状は種の初期精神力(個体差なし。将来は遺伝子)。筋力・体力も現状は種の値。種の値・係数(攻撃係数・防御係数・`wakefulness_per_mind`)を `SpeciesDef` に追加(spec §2.2)。攻撃力・防御力の計算関数(戦闘は `docs/tasks/x_10`)。`to_dict` / 越境のシリアライズ・API の Entity に含める。
- **14c 睡眠と覚醒度(コアタイムなし)**:
  - `state`(`awake` / `sleeping` / `unconscious`)、`wakefulness`、`wakefulness_max`(= 精神力 × `wakefulness_per_mind`。**体力は使わない**)。覚醒中は毎 tick `wakefulness_decay_per_tick`(**行動によらず一定**)で減り、睡眠中は `wakefulness_recovery_per_tick` で回復。覚醒度 0 で意識消失(強制睡眠)。`consciousness_regain_level` に達したら通常の睡眠へ。
  - **入眠**: 覚醒中で安全な個体を、`sleep_check_interval_ticks`(600)ごとに判定。`sleep_pressure = wakefulness_pressure_gain × (1 − x) + cycle_pressure_gain × sleep_cycle_amplitude × sleep_rhythm`(両 gain は 1.0、`x` = 覚醒度 ÷ 最大値)に `(1 − hunger_level) × (1 − thirst_level)` を掛け、≥ 1 で必ず入眠、0〜1 は確率を `sleep_pressure_exponent`(n = 20)乗した値に `sleep_probability_gain`(0.1)を掛けた値が確率(入眠圧の大小によらず同じ式。1 以上になれば必ず入眠 = 入眠圧 1.122 以上。spec §5.2)。覚醒度の減少は Player・Fox 88,200 tick、Rabbit 91,800 tick(周期を安定させる値。spec §5.2)。記録のない個体の `sleep_peak_tick` は種の標準入眠時刻(`sleep_standard_onset_tick`)。個体は直近 5 回の入眠 tick(`sleep_onset_history`)を持ち、周期(`sleep_cycle_ticks` = 86,400)内の位置を 1 時間(3,600 tick)に丸めた最頻値を `sleep_peak_tick` とする。
  - **起床**: 睡眠中の個体を、同じ間隔で判定。`wake_probability = clip₀₁(σ↑(x) + wake_hunger_weight × hunger_level + wake_thirst_weight × thirst_level)`(`σ↑` は個体の `wake_midpoint`・`wake_steepness` の右上がりシグモイド)。個体の値は現状は種の定数(将来は遺伝子)。
  - 判定は、個体単位の定期アクション(entity モード。入眠・起床で切り替え)で行う。初期個体の覚醒度は最大値の 30〜100% の乱数(決定論的)。
  - 眠っている間は AI が考えない・移動/飲水/捕食をしない。Player のコマンドは拒否(`asleep` / `unconscious`)。イベント `fell_asleep` / `woke_up` / `fainted`。`can_eat` の「意識がある」を有効にする。**惑星・時計には依存しない。**
  - Player も対象。サーバ設定で Player の睡眠を無効にできる。
- **14f スタミナ・休憩・体力とスタミナの増減表**(spec §6):
  - `stamina`(最大値 = 現在の Health。常に `stamina ≤ health`)。**状態ごとの増減(毎 tick)**: 動作中(直近 `idle_after_ticks` = 60 tick 以内に行動)は回復なし、静止は体力 + 0.000772・スタミナ + 0.007716、休憩・睡眠・意識消失は体力 + 0.003472(Rabbit 0.003968)・スタミナ + 0.034722(Rabbit 0.039683)、欠乏(水分 0 または Energy 0)は体力 − 0.003086(1 つあたり)で回復は止まる。**アクションごとの消費**: 移動 − 0.005、捕食 − 0.025、飲水 − 0.01(スタミナ)。体力が変わるたびにスタミナを `min(stamina, health)` に切り詰める。
  - **休憩(`rest` アクション)**: Player はコマンド `rest`、NPC は安全でスタミナ・体力が低いときに休む。休憩中は覚醒したまま、覚醒度は回復しない。移動・飲水・捕食を始めると終了。安全でないときは入れない。
  - スタミナ不足の行動は拒否(`exhausted`)/ NPC は休憩。`can_eat` の「体が動く」にスタミナ ≥ 捕食の消費を追加。イベント `rest_started` / `rest_ended`。
  - 増減は、状態・アクションの表(spec §6.3・§6.4)をデータとして持ち、`living.py` / `animal.py` が表どおりに増減させる(表を変えるだけで調整できる構造)。
- **14g 気温による消費**(spec §6.9。14f の後): 惑星に `temperature_c`(earth 20 ℃)。水分の消費を `基準の消費 × hydration_temp_factor(T)` に(水分は気温のみで減る)。スタミナに、快適範囲外の度数に比例する毎 tick の消費(全状態)。`/config`・スナップショット・CLI に気温。テスト: 水分の消費が表の値(0・20・35・40・60・100 ℃)と一致、快適範囲内でスタミナの消費 0、純増減(回復 − 消費)、20 ℃で現行の水分の減少と同じ。 水分の消費は指数関数(`1/288,000 + exp(0.2×(T−40))/19,200` /tick × 種の係数。40 ℃で 5 時間、0 ℃で約 80 時間、100 ℃以上で 1 tick で蒸発)。
- **14d API/CLI**: Entity・`/config` の `species` に新しい値。CLI の状態バーに覚醒度・スタミナ・状態、眠っている動物の表示(大文字)、`rest` のキー。
- **14e 検証**: 4 日分のシミュレーションで、植物・動物の推移を記録(`docs/tasks/1_13` の表と比較)。睡眠の長さ・周期・意識消失の頻度が、仕様書の試算(spec §5.6)と同程度であること。

## 完了条件(テスト)
- **自動捕食**: 空腹でない NPC は触れた獲物を食べない。空腹かつ `can_eat`(意識がある ∧ Energy > 0 ∧ スタミナ ≥ 消費 ∧ 安全)なら食べる。眠っている/意識消失の NPC は食べない。安全でない(戦闘状態・落下中の旗を立てた場合)は食べない。Player の `eat` は睡眠中に拒否される。
- **能力値**: 個体の `mind` が種の初期精神力に等しい(個体差なし)。`wakefulness_max` が精神力 × 係数に等しい。**体力(最大値も現在値も)を変えても覚醒度の最大値・減少・回復・入眠確率・起床確率が変わらない**。Health が低くても覚醒している。筋力が攻撃力・防御力に影響し、体力は影響しない。
- **覚醒度**: 覚醒中に一定量ずつ減り(行動によらない。休憩中も減る)、睡眠中に回復し、最大値で頭打ち。0 で意識消失し、意識が戻る水準まで起床の判定をしない。
- **入眠(入眠圧)**: 覚醒中で安全な個体だけを、`sleep_check_interval_ticks` ごとに判定。入眠確率 = `min(1, sleep_probability_gain(0.1) × sleep_pressure ^ sleep_pressure_exponent(20))`(1 以上になれば必ず入眠)。覚醒度が低いほど・睡眠リズムの頂点に近いほど高い。飢え・渇きレベルが 1 なら 0。多数の試行で、期待値と一致する。直近 5 回の入眠 tick の記録、周期内の位置の 1 時間丸めと最頻値(同数なら最も新しい記録)、`sleep_rhythm`(頂点で 1・反対側で 0)、記録なしの個体は標準入眠時刻を頂点とすることを、表で検証。n による確率(入眠圧 1 以上は必ず入眠)も検証。簡略計算モード(`lite` / 定刻睡眠、spec §5.9)は、将来の実装(TODO G-33)で、この段階では実装しない。覚醒度の減少の速さは、周期のずれ(spec §5.2)をシミュレーションで見て再調整する。
- **起床確率**: 睡眠中の個体だけを同じ間隔で判定。式どおり(覚醒度が高いほど高い。飢え・渇きのレベルに比例して加算。0〜1 に収まる)。多数の試行で、期待値と一致する。
- **睡眠の周期**: 試算(spec §5.6)と同程度: 起きている約 16 時間、眠る約 8 時間、意識消失なし、数日にわたって安定。睡眠が日の時刻(惑星の時計・`day_length_ticks`)に依存しない。コアタイム・前後の余裕のパラメータが存在しない。
- **増減表**: 状態ごと(動作中・静止・休憩・睡眠・意識消失・欠乏)の毎 tick の増減が、表の値どおり。アクションごとのスタミナの消費(移動 0.005・捕食 0.025・飲水 0.01)。**体力が変わるたびに `stamina ≤ health`**。体力が減っていると、スタミナの回復も体力値までで頭打ち。回復は体力の 10 倍。行動をやめて `idle_after_ticks` 後に静止の回復が始まる。欠乏では回復しない。
- **休憩・スタミナ不足**: `rest` で休憩に入り、体力・スタミナが睡眠中と同じ速さで回復する。スタミナ不足の行動は `exhausted` で拒否される/NPC は休憩する。
- **戦闘状態・安全**: 常に偽/真(当面)。戦闘状態・落下中の旗を立てる API のテストで、入眠しないこと・`can_eat` の拒否を確認。
- 眠っている動物の AI が動かない(移動・飲水・捕食なし)。代謝は続く。
- API・CLI: 状態・覚醒度・スタミナの表示、Entity に含まれる。
- 性能: 動物の毎 tick の追加処理が軽い(1 tick の平均処理時間を計測して記録)。

## 実装結果(2026-11-06)
- **実装した範囲**: 14a(空腹 ∧ `can_eat` で自動捕食)、14b(能力値)、14c(覚醒度・入眠圧・起床確率・意識消失・睡眠リズム)、14f(スタミナ・休憩・増減表)、14g(気温による水分・スタミナの消費)、14d(API・CLI)、G-34(earth の tick 0 = 00:00)。`lite`(G-33)・戦闘・落下は未実装(`in_combat`・`falling` は旗だけ)。
- **主なファイル**: `core/sleep.py`(入眠圧・確率・直近の入眠時刻・睡眠リズムの純粋な関数。`sleep_check` ハンドラ)、`core/animal.py`(状態・覚醒度・スタミナ・休憩・`can_eat`)、`core/species.py`(パラメータ、水分の指数関数)、`core/planets.py`(気温)、`core/ai.py`(休憩・空腹時だけの捕食)、`core/region.py`(コマンドの拒否 `asleep` / `unconscious` / `exhausted` / `unsafe`、`rest`)。
- **テスト**: 171 件(新規 `test_sleep.py`・`test_animal_state.py`、CLI・API の追加分)が通る。確率の表(入眠・起床)・増減表・水分の気温依存(0・20・35・40・60・100 ℃)・スタミナの純増減・Region 越境のシリアライズを検証。
- **睡眠の周期(実装で個体を多数回した結果。簡易モンテカルロと一致)**: Rabbit(16 個体 × 10 日)起きる 16.4 時間・眠る 7.4 時間・入眠から入眠まで 23.85 時間・ずれ −0.15 時間/周期・意識消失 2/159。Fox(12 個体 × 8 日)15.5 時間・8.2 時間・23.76 時間・−0.24 時間/周期・意識消失 2/96。

- **結果の読み**: 3 日分の `docs/tasks/1_13` の検証(空腹のときだけ食べる)よりは持つが、**生態系は 3 日目に崩壊する**。Rabbit が 3 日で 560 まで増えて草・小麦を食べ尽くし(Grass 72)、その後に Rabbit が 1 に激減する。Fox は残るが、獲物がなく、いずれ絶滅する。バランス調整(TODO G-2)が必要。
- **意識消失が 531 回(多い)**: 飢え・渇きの個体は、入眠圧に `(1 − 飢え)(1 − 渇き)` を掛ける(深刻な飢えでは入眠圧 0)ので眠れず、覚醒度が 0 になって意識消失する。草・小麦の枯渇後に急増(3 日 228 → 3 日 12 時間 468)。**飢えた個体が眠れない設計の帰結**(仕様どおり。見直す場合は spec §5.2 の飢え・渇きの扱い)。
- **注意(要判断)**: `can_eat` が「Energy > 0」を要求するため、**Energy が 0 の個体は目の前に獲物がいても食べられない**(仕様 §1.1 のとおり)。飢餓の悪循環になりうる。
- **未対応・残り**: 睡眠中の動物の割合は、初期の覚醒度の揃い方で 10〜47% と揺れる(spec §5.7)。Player の睡眠・休憩は CLI で実機確認が必要。`docs/research/plant-processing.md`・`docs/research/headless-speedup-proposal.md` の簡略化は検討中(G-35・G-36)。
